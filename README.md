# ALERT : Anomaly Localization & Early Real-Time Detection

ALERT est un logiciel de démonstration clé en main, libre d’accès, destiné aux usages académiques et industriels, permettant de détecter et de localiser en temps réel des anomalies dans un signal vidéo.

## Démonstration Vidéo

[![Regarder la vidéo](https://webtv.centralesupelec.fr/thumbnails/videos/v126d5bdf432dzs5gmpm0is8jx9831/thumb_large.jpg)](https://webtv.centralesupelec.fr/videos/stage-alert/)


## Prérequis

### Créer un environnement virtuel

```shell
python -m venv .venv
source .venv/bin/activate
```

### Installer les dépendances

Ouvrez votre environnement python et lancez depuis la racine du projet:
```shell
pip install -e .
```

## Démarrage rapide

```shell
python main.py            # puis ouvrir http://127.0.0.1:8000
```
